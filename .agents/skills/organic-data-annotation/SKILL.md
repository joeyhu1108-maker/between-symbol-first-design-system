# 有机式数据标注层

Organic Data Annotation Overlay 是这套视觉语言的描述性名称，不是既有艺术流派的正式名称。让作品呈现出正在被观察、命名和追踪的状态：远看主体完整，近看浮现精细的信息关系。

## 风格核心

- **保持主体。** 保留输入图的构图、比例、色彩、材质与主要物体位置。把标注当作附加的平面图形层，不要重新设计底图。粉紫色厚涂属于示例底图，不是本风格对其他图的配色要求。
- **有生长感的引线。** 使用发丝般的细线，自局部锚点舒展、弯曲、回环，偶尔分叉成根系、神经或触须般的支线。长曲线组织画面，短引线解释局部。线条是精细墨线，不是立体绳索或实体植物。
- **有明确指向。** 注释落在具体的轮廓、转折、几何结构或纹理区域。用极小实心点、空心圆标出连接处。避免随机撒线，每条注释引线应能追溯到被解释的对象。
- **微型标签。** 混合使用深色细长胶囊 tag、少量微型矩形标签与无边框文字；字体以细小等宽字为主。标签像依附在线上的信息节点，文字和框体都克制，不做大标题或说明面板。
- **科学手稿细节。** 少量加入断续椭圆轨迹、短刻度、虚线路径、微小编号与坐标十字。它们辅助关系与运动感，不铺满画面。
- **信息的层次。** 构图不对称、疏密有节奏，避开主体的关键视觉区域。默认细线清晰、tag 可辨认，但视觉权重低于原画。依据背景调整灰黑、灰白、暖炭色，少量强调色取自原图。

## 内容与密度

标签围绕图像本身的结构、变化、关系和状态展开，例如 `surface memory`、`contact point`、`attraction field`、`vector drift`、`resonance`、`growth path`、`phase / 02`、`node_01`。适当使用诗性命名，让科技感与主体有叙事关系。用户指定的文字优先，不默认把所有作品标成同一组词。

对类似参考的长幅复杂图，可从 5–7 条主要细曲线、约 12 个微型标注开始；这是密度参考，不是固定配额。简单主体、小尺寸图应相应减量。短标签、文字可辨认、少量真正有意义的连接，比增加符号数量更重要。

装饰性编号和参数不得被解释为真实测量数据。涉及真实数据图时，只使用用户提供或已验证的数据。

## 执行

1. 查看输入图，识别适合连接的局部结构及可容纳标签的区域。首次复用或需要校准尺度时，查看 [已获认可的示例](references/approved-example.png)，并读 [示例说明及生成提示词](references/example-prompt.md)。示例用于理解叠加层，不用于替换用户底图。
2. 用户要实际图片时，使用可用的 `imagegen` 技能和内置图像编辑工具；本技能负责视觉规范，工具使用规则遵循当前 imagegen 指引。以用户原图为编辑目标，明确只添加标注、保留其余视觉特征。用户只要提示词时，直接输出适配该图的提示词。
3. 根据主体选择标签词汇及锚点，把下面的模块改写成具体编辑指令。无需重新询问已明确的风格偏好。
4. 检查原画是否保持、线条是否真正细且有指向、标签是否微型且分布自然、文字是否出现明显乱码。需要调整时针对问题迭代，避免无关的整体重绘。
5. 展示结果。保存新版本，除非用户要求替换，否则不覆盖原图。示例图不意味着授权批量修改其他作品。

## 可复用提示词

> 保留原图主体、构图、比例、色彩和材质，只叠加一层精细的「有机式数据标注层」（Organic Data Annotation Overlay）。选取主体中有辨识度的局部结构作为锚点，从锚点伸出发丝般的细引线。线条像触须、根系或神经纤维一样自然弯曲、舒展、回环，少量分叉成树状支线，沿主体轮廓与画面留白游走。每条注释引线都应明确连接一个具体对象。
>
> 在部分线条末端、转折或分支节点附加微型标签，混合深色细长胶囊 tag 与无边框的细小等宽文字。标签内容与主体的结构、状态、变化和关系相关，简短、可辨认，带有观察记录与诗性命名的意味。局部加入极小圆点、空心圆、编号、短刻度、断续椭圆轨迹和少量辅助线，形成“锚点—引线—节点—注释”的关系。
>
> 用少量长曲线串联画面，短支线补充局部细节，分布不对称、疏密有节奏。使用适合原图的灰黑、灰白或暖炭色细线，确保在背景上可见；标签尺度保持微小，避免遮挡主体关键部位。整体像覆盖在作品上的精密研究手稿，兼具科学图解的观察感与有机线条的生长感。

## 避免

粗重连线、大标签、大标题、整齐铺满的流程图、密集电路板纹样、霓虹发光 HUD、随机乱码、没有指向的装饰线、标签遮挡主体、把细线生成实体绳索、为了科技感改变原画配色或材质。
