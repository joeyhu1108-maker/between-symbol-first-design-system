# BETWEEN — 12 个关系符号的动态语言

## 设计依据

人格：有机、敏感、相互回应。原图为 1448×1086 的十二宫格；每格 362×362，黑色骨架、靛蓝与朱红节点。原图中的棋盘格与颗粒不进入矢量，保留轮廓、重心、负空间和关系方向。用少量三次贝塞尔曲线重建，而非逐像素描摹。

采用本地 pixel2motion 的拆层与动效验证流程，按用户要求使用真正 Lottie JSON 与本地 lottie-web 播放器。SVG 与 Lottie 由同一几何源生成。部件按绘制顺序排列，交织符号单独拆分前后穿行线。

## 动作结构

| 状态 | 时间 | 用途 |
| --- | --- | --- |
| idle | 4 秒 | 小幅呼吸、柔和传递；首尾完全一致 |
| hover | 0.8 秒 | 先回应再回落；只对鼠标悬停及键盘聚焦触发 |
| tap | 1.8 秒 | 蓄力约20%、主动作约50%、跟随回落约30% |

按压表面反馈 120ms；内部部件错峰，重的骨架慢，节点和叶尖随后响应。缓动以 (0.4,0,0.2,1) 为主，实际写入 Lottie 关键帧。所有动作结束回到同一个静态轮廓。手机端轻触即播放 tap，不依赖 hover。支持键盘、减少动态、离屏暂停与后台暂停。

| 符号 | 叙事 |
| --- | --- |
| 种匣 · 委托 | 外壳先打开，红色种子落入，外壳轻轻收回 |
| 镜叶 · 模仿 | 蓝叶先动，红叶镜像回应，然后产生微小偏差 |
| 并茎 · 陪伴 | 两株各自生长，叶尖以错开的节拍呼吸 |
| 寄枝 · 依赖 | 小枝施加重量，主枝弯曲承托并回弹 |
| 环束 · 规训 | 黑环向内夹合，红环伸展，边界重新放开 |
| 破壳 · 反抗 | 壳先向内蓄力，再打开，种子跃起，短线随后回应 |
| 交汇结 · 协商 | 红蓝两路围绕中心改道，交织处保持前后关系 |
| 合生 · 共创 | 红蓝向交点汇入，中心节点成为第三个回应 |
| 争隙 · 竞争 | 两侧曲线轮流挤压空隙，节点依次穿行 |
| 共脉 · 共养 | 三条脉络依次传递波动，端点接收和释放 |
| 断丝 · 疏离 | 两端短暂靠近，红点传递，随后重新留出距离 |
| 分叉 · 未定 | 根保持稳定，不同方向的枝叶先后展开 |

## 实现与检查

60fps；idle 为 0–240 帧，hover 为 240–288 帧，tap 为 288–396 帧。每份 JSON 带三个同名 marker。所有形变要求相同顶点拓扑；所有关键帧区间必须首尾还原。实际图形限制在 362×362 内。

展示页支持 `?symbol=07&t=600`（tap 中的毫秒位置）、`?static=1`；准备完成后设置 `window.__p2mReady`。速度调整立即作用于当前播放。提供三个同源动作小样，便于比较轻呼吸、悬停回应与完整叙事。

## 作品中的动态语言

资源统一放在 `seed-universe/motion/`，[主作品](http://127.0.0.1:8765/) 与手机抽卡入口共用 `seed-universe/symbol-interface.js`；[独立动作展示](http://127.0.0.1:8765/motion/) 用于检查和下载，不承担作品主流程。

界面按行为选择符号：01 表达承接与打开，10 表达洗牌与传递，07 表达把下一次抽卡交给另一端，08 表达融合与成功接收，12 表达生成与展开。这些编号指向动作资源，不是实体卡身份。实体卡面、二维码、会话状态与生成任务继续使用原有数据。

等待时只让当前可见的状态符号轻呼吸；动作触发时播放完整反馈。完成状态回到静态。动画播放不会代替后端确认，也不会自动提交物理打印。
