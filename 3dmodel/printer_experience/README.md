# 花园 · 打印机创作剧场

当前呈现为完整机器待机 → 错峰装配与轻微弧线运镜 → 符号与颜料汇聚 → 同源作品连续显影。详见 [CINEMATIC_NOTES.md](CINEMATIC_NOTES.md)。下方早期宇宙时序及旧 `garden_film.mp4` 为历史版本；当前审阅文件为 `printer_cinematic.mp4`。

当前版本以“花园”为最终作品概念，固定抽象绘画语言，让种子变量改变画面。已完成 Three.js 动画、两张真实 AI 花园样张、统一 Style Scale、本地规则生成、编号 PDF 和待连接的纸张打印接口。

## 查看

- 双击 `start.command` 启动本地服务。
- `http://127.0.0.1:8765/`：旋转粒子宇宙与生成流程。
- `http://127.0.0.1:8765/garden_style.html`：固定风格尺度及两张 AI 样张。点击样张进入对应动画。
- `garden_film.mp4`：25 秒、1280×720、30 fps 的新版影片；`archive_v1/` 保留旧版。
- `http://127.0.0.1:8765/input`：原始种子显影台，点击“送入重组打印”原样传递 m/n/a/b/seed。

## 新动画顺序

| 时间 | 画面 |
| --- | --- |
| 0–6 秒 | 旋转的立体模态粒子宇宙，尚无打印机 |
| 6–11 秒 | 同一批高斯色粒沿弯曲路径凝成打印机，全程保持浅色暖白背景 |
| 11–14 秒 | 高斯打印机短暂停留，结构清晰可辨 |
| 14–21 秒 | 再次变换，粒子采样最终 artwork 的颜色，形成有深度的抽象花园色域 |
| 21–25 秒 | 打印机归位，真实 artwork 纹理沿纸路输出，完整作品短暂停留 |

静止时可拖动查看；支持低动态模式。开场在等待点击时也持续旋转。粒子是三维模态叠加场；高斯部分是各向异性透明点渲染和网格结合，不是照片训练的 3DGS，也不宣称求解真实振动板。

## 固定与随机

`garden_style.json` 是统一配置，`GARDEN_STYLE.md` 解释风格取舍。抽象度、绘画肌理、色谱、冷暖倾向与非对称性固定，模态与 seed 改变构图。`garden_style.py::ai_prompt` 为每个任务保存同一套提示词到 `jobs/<id>/ai_prompt.txt`，同时保存 `style_version` 和 `style_scale`。

两张实际 AI 样张：

- `SG-20260912-0008-13DE61CD`：III × V，seed 333341133。
- `SG-20260912-0010-05792CA4`：IV × IX，seed 91827364。

每张保留模态结构 `guide.png`、AI 成品 `ai_original.png`、编号 `artwork.pdf` 与来源清单。编号位于打印页边缘，绘画本身无标签。参考第 1、4 张为同一图，只记一次权重。

普通新建任务目前运行本地抽象色域生成器，标记 `local_garden`；AI 样张标记 `ai_imagegen`。在线 AI 自动调用仍未配置。`attach_ai_artwork.py` 可将真正 AI 输出绑定到尚未打印的任务。不能用本地程序输出冒充实时模型推理。

## 等待与打印

25 秒为完整演示；`?mode=live` 根据真实文件到达时间收束，快速生成约 21 秒完成。慢任务继续变换，超过 30 秒说明种子已保存；没有结果不进入成功状态。`?debug=1` 可验证慢任务与失败。不会循环假进度或自动重复打印。

作品归档到 SQLite 与 `jobs/`；相同请求不会重复编号。用户已说明纸张打印机留待现场连接。连接后刷新队列、选择实际设备，调用 CUPS 提交 PDF；只报告进入队列，不将其当作出纸完成。默认 A5、105×180 mm 图像，现场应按设备纸宽和驱动调整。

## 验证与文件

启动服务后运行 `node verify.mjs`。覆盖时序、参数传递、幂等、文件、风格版本、无效输入、缺失队列与跨来源写入拒绝。浏览器检查三维显示、持续旋转、凝形、二次变换、最终图片、响应式和低动态模式。

核心文件：`app.js`、`timeline.js`、`garden_universe.js`、`garden_style.py`、`server.py`。模型来自 `assets/printer.glb`，可编辑 Blender 原始文件在 `../printer_v2/`。Python 使用项目 `.venv`；依赖 numpy、Pillow、reportlab，导出影片另需 imageio-ffmpeg。Three.js 已本地化并附许可证。
