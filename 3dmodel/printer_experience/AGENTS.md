# 当前作品约定

- 本目录的最终 artwork 概念为“花园”。每次生成前使用 `garden_style.json` 与 `GARDEN_STYLE.md`，以 `garden_style.py::ai_prompt` 为统一提示词来源。
- 保持固定风格尺度，只让输入模态与个体种子改变构图。排除具象种子标本、器官与具体花园风景。
- 3D 效果最新约定见 `PRINTER_EFFECTS.md`：首页完整机器 → 默认正面模块组装（允许拖动旋转）→ 打印状态才启用高斯色粒 → 出纸。组装阶段不使用高斯溶解。
- 保留编号、输入变量、风格版本和生成来源。区别真正 AI 图像与本地规则预览。
- 保留可编辑网格；高斯渲染是表现层，不宣称已训练照片重建模型。

- 全程使用浅色暖白背景，首页不再显示粒子宇宙；不要因宇宙概念改为深色。

- 花园配色以粉色和很淡的紫色为主，减少蓝绿冷色；加入约20%油画感，以及轻微颜料剥落、磨损和褪色。

- 图像需要可见的关系叙事。使用 `story.py` / `STORY_RULES.md`，先确定卡牌动机、视角和画面证据，再生成图像；故事是艺术解释，不是人格判断。概率差异遵循 `RARITY.md`，如实显示 1/66 等数值。

- 本分支当前范围仅为 3D 打印机呈现与效果，artwork、故事和概率内容由主流程负责。
