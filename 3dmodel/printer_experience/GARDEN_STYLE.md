# 花园 · 固定风格尺度 v1.1

种子是输入，花园是种子落下后产生的色彩、空间与关系。最终 artwork 是**非常抽象的绘画场域**，采用不对称、多中心、可延伸到纸面之外的构图。

## 风格配比

| 来源特征 | 固定权重 | 保留的视觉语言 |
| --- | --- | --- |
| 粉色、玫瑰色的表现性绘画 | 38% | 颜料叠压、刮擦、覆盖、断裂笔触 |
| 柔粉、半透明的有机空间 | 37% | 发光空域、薄层渗化、细线与悬浮色点 |
| 很淡紫色与暖白的色彩空间 | 25% | 冷暖相邻、空间深浅、模糊边界 |

用户第 1、4 张参考为同一幅图，合并为一个来源，不重复加权。这些数值是统一的生成指导权重，不是对模型输出像素的测量。

## Style Scale

| 维度 | 固定值 |
| --- | --- |
| 抽象度 | 0.96 |
| 有机运动感 | 0.78 |
| 颜料饱和度 | 0.62 |
| 透明叠层 | 0.60 |
| 手势与笔触 | 0.66 |
| 细线密度 | 0.46 |
| 暖色倾向 | 0.88 |
| 非对称性 | 0.85 |

统一色谱：粉色／玫瑰／柔粉约55%，很淡紫约25%，暖白约15%，其他低饱和点缀约5%。约20%油画笔触，80%仍为空气感叠层；加入细微龟裂、颜料剥落、边缘磨损和褪色。细节局部聚集，采用不等距排线、未闭合框架、错位描线、不可读涂写与擦除后再描画。

## 什么可以随机

- `m、n`：色域节奏、边界的弯折、空间分隔。
- `a、b`：交错方向、冷暖色域的关系。
- `seed`：构图、笔触、色点、空域和覆盖层的位置。

固定风格尺度，随机组合画面内容；保存种子和风格版本，允许重现同一作品。每次新生成使用新的个体种子；“回放”始终对应已归档的同一件作品。

## 不进入这套风格的形态

具象花园、可辨认的花朵或植物、居中对称的种子/细胞标本、解剖图、脑与器官、塔罗边框、科幻海报。克拉尼图形用于隐藏的结构约束，不能变成覆盖画面的生硬网格。编号排在打印页面边缘，不加入绘画主体。

## 执行位置

- `garden_style.json`：唯一机器可读风格配置。
- `garden_style.py::ai_prompt`：每个新任务都保存统一提示词到 `jobs/<id>/ai_prompt.txt`。
- `garden_style.py::render_garden`：相同色谱和尺度下的本地规则预览，明确标记 `local_garden`。
- AI 样张 VIII、X：真实 imagegen 输出，保存到各自 `ai_original.png`，标记 `ai_imagegen`。在线 AI 自动调用仍待接入；不把本地规则绘画称为模型推理。

## 动画语法

0–6 秒：立体模态粒子宇宙持续旋转；6–11 秒：同一批粒子凝成高斯打印机；11–14 秒：形态短暂停留；14–21 秒：再次流动，成为带有最终作品色彩的空间图形；21–25 秒：花园落纸，留出完整作品的停留时间。

三维场由周期模态叠加构成，是克拉尼启发的体积视觉模型。高斯部分使用各向异性色粒渲染与网格结合，不宣称为真实弹性板求解或多视角照片训练的 3DGS。


## 情感与概率
