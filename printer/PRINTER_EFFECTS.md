# 打印机创作动效

`spring-long-20260913`：底座待机 → 快速缓入缓出装配 → 接触回弹与齿轮试转 → 上盖缓落 → 符号显影 → 同源作品连续出纸。

## 装配与镜头

- 零件直接从近处向内装配，没有先向外炸开的阶段。约1.5秒形成打印机主体，3.3秒全部收稳。
- 核心、传动、背架、后板、左右面板错峰进入；采用五次缓动曲线保证位置与速度连续。
- 上盖1.60秒开始，2.47秒落位，随后0.72秒轻颤衰减。盖子构件使用一致时序。
- 主要接触事件触发机身自身的小幅位移和倾摆；弹簧位移行程按1.8倍调整，旋转幅度不放大。3.3秒后反应严格归零。
- 齿轮到位后短促试转两次，并保留转角衔接打印。
- 镜头从正面轻绕传动机构，再回到正面随纸路下移；用户拖动、滚轮或方向键接管，Home/双击回正面。
- 低动态模式关闭自动绕行、回弹、试转、符号飞行与高斯色粒，保留轻量装配和出纸。

## 创作与出纸

作品与纹理就绪后，最快4.2秒开始符号显影。断环、分叉等手绘符号采样本任务的模态节点，颜色采样本任务原图；随后才出现局部颜料流。纸张使用连续片元裁切，不按网格行跳动。

显影是创作过程的视觉演绎，不冒充在线AI逐笔计算。最终直接恢复本任务原始图片纹理；编号PNG/PDF、卡牌算法和生成器保持由后端提供。慢生成时保持等待，不提前出纸。

## BETWEEN 集成

保留 `game-cards.js` 对应的卡牌编号与名称，以及 `embed=1` 的同源 iframe 协议：`between-printer-start` 启动，`between-printer` 返回 ready / progress / complete / error。进度使用新时间线的 `finishAt`，避免提前停在99%。

嵌入默认 live 模式，正常21秒；独立预演25秒。动画 complete 仅表示视觉演绎完成，主控台仍由既有 IPP 打印反馈决定何时显示实际出纸成功。

`printer_motion.js`：轨迹、缓动、回弹、试转和镜头。
`printer_effects.js`：模型、连续纸路、深度遮挡和渲染。
`printer_creation.js`：符号、颜料与原图纹理恢复。

检查：`node printer/verify_printer_effects.mjs`；本地服务启动后 `node printer/verify.mjs`（非默认端口可设 `PORT`）。
